# astrbot_plugin_dorm_electricity

重庆三峡科技大学宿舍电费余额查询插件（AstrBot）—— 让机器人在 QQ 里帮你查宿舍还剩多少电费。

## 功能

- **LLM 工具 `get_dorm_power_balance`**：机器人自主判断并调用。用户问「我宿舍电费还剩多少」「够不够用」时，它会自己去查。
- **`/电费`**：查询已绑定房间的余额、扣费日期、本月用量
- **`/电费 绑定`**：自助绑定宿舍 —— 依次选「校区 → 楼栋」，再回复房间号，选完立即查一次并保存
- **`/电费 房间`** / **`/电费 解绑`**：查看当前绑定 / 解除绑定

## 数据来源

余额数据来自学校能源自助查询缴费系统的后台接口。

微信端的页面需要公众号网页授权（`snsapi_base`）才能打开，**但后台的查询接口本身不校验身份**，只认「校区名 + 房间号」两个参数，所以服务端可以做只读查询。

> ⚠️ 请合理使用。插件默认只允许查询自己绑定的房间，不要改成高频轮询或批量遍历房间号 —— 那会给学校系统带来压力，也可能让你的服务器 IP 被限制。

## 安装

方式一：AstrBot 面板 → 插件市场，搜索仓库名安装。

方式二：手动 clone 到 `data/plugins/` 目录：

```bash
cd /path/to/AstrBot/data/plugins
git clone https://github.com/misha-233/astrbot_plugin_dorm_electricity.git
```

依赖 `httpx`，AstrBot 已自带，无需额外安装。

## 配置

在 AstrBot 面板的插件配置中设置：

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `base_url` | string | 学校 ashx 接口地址 | 一般不用改 |
| `default_school` | string | `重庆三峡科技大学百安校区` | 未绑定房间但指定了房间号时使用的校区 |
| `request_timeout` | float | `15` | 接口超时（秒） |
| `allow_self_bind` | bool | `true` | 是否允许所有人自助绑定；关闭后仅管理员可绑定 |
| `allow_any_room` | bool | `false` | 是否允许查询未绑定的房间号。默认关闭，避免被当成「任意宿舍余额查询器」 |
| `low_balance_threshold` | float | `10` | 余额低于该值时附带一句提醒，填 `0` 关闭 |

```
用户：/电费 绑定
机器人：请选择校区（回复序号，「取消」可中止）：

用户：1

        请选择楼栋（回复序号，「取消」可中止）：
        1. 桂花苑1舍
        ...

用户：17
机器人：已选：重庆三峡科技大学百安校区 某栋宿舍（共 635 个房间）
        请直接回复你的房间号，例如：L1-0001、L1-0002 ...

用户：L1-0001
机器人：绑定成功！
        🔌 重庆三峡科技大学百安校区 某栋宿舍 L1-0001
```

绑定后，私聊或群聊发 `/电费` 都能查（绑定关系按「平台 + QQ 号」保存，不分会话）。

## 定时余额预警（可选）

AstrBot 内置 cron 能力，不需要本插件额外做后台任务。在**私聊**里对机器人说：

> 每天早上 7:30 查一下我宿舍电费，低于 10 元就提醒我，够用就不要发消息

它会在到点时唤醒自己、调用本插件查询、按结果决定是否发消息。

> 提示：cron 唤醒时构造的是合成事件，`sender_id` 取的是**会话 id**（群聊就是群号）。所以定时任务建议在私聊里创建；否则插件识别不到你的绑定。

## 隐私说明

- 绑定信息保存在 AstrBot 的插件数据目录（`data/plugin_data/astrbot_plugin_dorm_electricity/bindings.json`），**不进插件配置、不进代码**；
- 插件配置里只有行为开关和校区名，没有任何具体房间号；
- 查询请求不携带任何微信身份（无 cookie、无 openid），只带「校区 + 房间号」。

## 已知限制

- 依赖学校系统的接口形态，若校方日后加鉴权或调整参数，插件会失效；
- 接口为明文 HTTP，仅用于只读查询余额，不涉及缴费、送电等写操作；
- 插件不含缴费/充值功能。
